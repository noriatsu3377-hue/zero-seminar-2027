FOR YOU

こんな方におすすめ

  • 関節へのアプローチを基礎から体系的に学びたい方
  • ADVANCEまで進み、関節調整を施術の柱にしたい方

対象：トレーナー・セラピストなど、身体に関わる専門職の方
受講条件：2日間とも参加できる方

GOALS

学習目標

  • 関節可動域と関節の遊び、モビライゼーションとスラストの違いを理解する
  • 適応・禁忌の確認と、評価 → 調整 → 再評価の流れを身につける
  • 下肢・骨盤・腰部から、上肢・胸郭・頸部・顎までの基本の評価と調整を練習する

※学習目標は講座で扱う範囲を示すものです。技術の習得や施術の効果を保証するものではありません。

LECTURE & PRACTICE

講義と実技で扱う内容

講義で扱う内容

  • 関節可動域と関節の遊び、モビライゼーションとスラスト、キャビテーション
  • 音の有無だけを成功の基準にせず、評価 → 調整 → 再評価で判断する考え方
  • 適応・禁忌、既往歴、神経・血管症状、レッドフラッグ、説明・同意・記録
  • 関節ごとの制限、左右差と荷重戦略、隣接関節との関係

実技で扱う内容

  • 足趾・足部・足関節、膝、股関節・骨盤帯、腰部の評価と調整
  • 指・手・手首・前腕、肘、肩・肩甲帯の評価と調整
  • 胸椎・胸郭・肋骨の分節評価と、呼吸を利用した低負荷の調整
  • 頸部のスクリーニングと低負荷のモビライゼーション
  • 顎・頭部の評価と低負荷のアプローチ
  • 立位・歩行・スクワットなどでの再評価と実技チェック

過去の講座資料にもとづく内容です。2027年の内容は確定後に更新します。

CURRICULUM

カリキュラム

DAY 1：下肢・骨盤・腰部

  1. 基礎概念・安全確認
  2. 足趾・足部・足関節
  3. 膝
  4. 股関節・骨盤帯
  5. 腰部・下肢の統合
  6. 動作での再評価と実技チェック

DAY 2：上肢・胸郭・頸部・顎

  1. DAY 1の評価手順・セットアップの復習
  2. 指・手・手首・前腕、肘
  3. 肩・肩甲帯
  4. 胸椎・胸郭・肋骨
  5. 頸部（低負荷のモビライゼーション）
  6. 顎・頭部
  7. 全身統合：問診・安全確認 → 動作評価 → 関節選択 → 調整 → 再評価
