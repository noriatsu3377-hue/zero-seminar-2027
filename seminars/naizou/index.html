零式-内臓調整 ― 神経アプローチ

内臓を強く動かすのではなく、神経系を踏まえて身体を調整する。

腹診・舌診・脈診による東洋医学の見立てと、臓器の解剖・生理・神経支配を学び、腹部の状態・呼吸・姿勢・運動機能をつなげて評価する講座です。相手の反応を確認しながら介入を選び、再評価と生活・運動への提案まで組み立てます。

FOR YOU

こんな方におすすめ

  • 腹部の緊張や張り、呼吸の浅さを訴えるお客様に、根拠を持って向き合いたい方
  • 東洋医学の腹診・舌診・脈診を、評価の一部として体系的に学びたい方

GOALS

学習目標

  • 臓器の位置・機能・神経支配を整理して説明できる
  • 腹診・舌診・脈診を、限界を理解したうえで評価の一部として扱える
  • 腹部の硬さを単一の原因に決めつけず、問診や呼吸・動作から考察できる
  • 伝統医学の見立てと現代医学のメカニズムを区別して説明できる
  • 反応に応じて介入・再評価・中止を判断できる
  • 内臓間の関係を踏まえ、生活・運動への提案まで組み立てられる

LECTURE & PRACTICE

講義と実技で扱う内容

講義で扱う内容

  • 零式がいう「内臓調整」「神経アプローチ」の定義と評価の全体像
  • 胃・小腸・大腸・肝臓・胆嚢・膵臓・腎臓・膀胱の解剖・生理・自律神経支配（心臓・肺・横隔膜・腹膜の位置関係は関連理解として）
  • 交感神経・副交感神経・腸管神経系、内受容感覚、脳腸相関、関連痛の基礎と解釈の限界
  • 東洋医学の実証・虚証と、ストレス・睡眠・食生活などの生活背景
  • 腹部が硬く感じられる背景（筋活動、呼吸と腹圧、膨満、接触への反応、体位）
  • 内臓間の関係（神経・機能・循環・呼吸・隣接関係・東洋医学の臓腑モデル）と、長期化する状態と疾病リスクの考え方

実技で扱う内容

  • 腹診：説明と同意、体位、腹壁の緊張・左右差・呼吸に伴う動きの観察
  • 舌診：舌の色・形・舌苔・湿潤状態と、観察に影響する条件
  • 脈診：速さ・リズム・強弱の観察と、測定条件・再現性
  • 3つの所見と問診・呼吸・動作評価の照合
  • 神経アプローチの実践：介入目標の設定、刺激量の調整、反応の比較、中止・再検討
  • ケーススタディ：問診 → 安全確認 → 評価 → 仮説 → 介入 → 再評価 → 生活・運動の提案

2027年カリキュラム案にもとづく内容です。過去に開催した講座の内容ではありません。

CURRICULUM

カリキュラム

2027年に向けて設計中のカリキュラム案です。時間配分・実技の詳細・各項目を扱う深さは、受付開始時にご案内します。

1．内臓の解剖・生理・神経支配臓器ごとに位置・機能・神経支配を整理し、内臓と神経系の関係を学びます。

内臓調整の目的と評価の全体像

  • 零式がいう「内臓調整」「神経アプローチ」の定義
  • 内臓の病気そのものを治療することと、身体の反応・機能を評価することの区別
  • 問診 → 観察 → 腹診・舌診・脈診 → 動作・呼吸評価 → 仮説 → 介入 → 再評価
  • 症状がある場所だけで判断しない考え方

臓器ごとの解剖・生理・神経支配

  • 主な対象：胃、小腸・大腸、肝臓・胆嚢、膵臓、腎臓・膀胱（消化器を中心に扱う）
  • 関連する基礎：心臓・肺、横隔膜、腹膜・腸間膜・後腹膜の位置関係
  • 共通の整理項目：位置と隣接構造、主な生理機能、自律神経支配と感覚情報の経路、血流・呼吸・体位との関係、問診項目、筋骨格系の反応と区別する視点、医療評価を優先する所見

内臓と神経系

  • 交感神経・副交感神経・腸管神経系
  • 迷走神経と骨盤内臓神経の役割の違い
  • 内臓から脳への求心性情報と、脳から内臓への調節
  • 内受容感覚、脳腸相関
  • 内臓体性反射・体性内臓反射・関連痛の基礎と解釈の限界
  • 感覚入力、痛み、防御的な筋活動、呼吸の関係（「交感神経は悪い」といった単純化はしない）
2．実証・虚証と腹部の状態東洋医学の見立てと生活背景から、腹部が硬く感じられる理由を分けて考えます。

実証・虚証と現代の生活背景

  • 東洋医学における実証・虚証の基本
  • 気滞・瘀血・痰湿・食積など、実証を考える際の伝統的な概念
  • 虚実が混在する見立て
  • ストレス、睡眠不足、食生活、飲酒、活動量低下などの生活背景と、腹部の緊張や膨満感の関係を問診から考える
  • 「現代人に実証が多い」は、講師が臨床で着目しているテーマとして扱う

腹部が硬く感じられる理由を分けて考える

  • 腹壁の筋活動や防御的な緊張
  • 呼吸時の動きと腹圧調整
  • 膨満、便通、食後の変化
  • 痛み、不安、接触への反応
  • 体位による変化
  • 腹部の硬さから臓器そのものの硬さや病変を断定しない。「いつ・どの条件で・何と一緒に変わるか」を評価する
3．腹診・舌診・脈診と動作評価3つの伝統的な診察法を、限界を理解したうえで評価の一部として練習します。

腹診

  • 説明・同意、体位、接触への反応
  • 腹壁の緊張、左右差、呼吸に伴う動き、不快感の観察
  • 刺激を増やさず、確認できる範囲を記録する

舌診

  • 舌の色、形、舌苔、湿潤状態の観察
  • 照明、飲食、口腔状態など観察に影響する条件
  • 単独の所見から疾病を断定しない

脈診

  • 伝統的な脈の捉え方の基礎
  • 速さ、リズム、強弱などの観察
  • 姿勢、運動直後、緊張など測定条件の影響
  • 評価者間のばらつきと再現性

所見の統合と動作評価

  • 3つの所見と問診・動作評価を照合する
  • 所見が一致しないときに結論を急がない
  • 医療上の確定診断と区別して説明する
  • 体幹回旋、前後屈、股関節運動、歩行などの評価
4．内臓間の関係と全身への影響「内臓連鎖」を6つの観点に分けて整理し、運動機能や長期的な健康との関係を学びます。

内臓機能と運動機能・身体全体

  • 不快感や痛みに伴う姿勢・筋活動の変化
  • 腹部の状態と呼吸・体幹運動・腹圧調整
  • 睡眠、疲労感、活動量、運動耐容能との関係
  • 動作が変化したことと、内臓の病理が改善したことを区別する

内臓間の関係（内臓連鎖）

  • 神経による調節・情報共有
  • 消化・吸収・排泄という機能上のつながり
  • 循環・代謝・ホルモンを介した関係
  • 呼吸・横隔膜・腹圧との関係
  • 解剖学的な隣接関係
  • 東洋医学における臓腑の関係モデル（現代医学の臓器と東洋医学の「臓腑」は同じ概念ではない）

長期化する状態と疾病リスクの理解

  • 慢性的なストレス、睡眠不足、過食、飲酒、活動量低下などの背景
  • 相関と因果、リスク要因と診断の違い
  • 伝統的な「実証」の説明と、現代医学の病態生理を別々に整理する
  • 生活背景が共通していても、個人の疾病を予測できるわけではないこと
5．神経アプローチと再評価相手の反応を確かめながら介入を選び、再評価し、必要なら中止する判断を練習します。

神経アプローチの実践

  • 介入の目標を先に決める
  • 接触・体位・呼吸・運動などの感覚入力を選ぶ
  • 相手の反応に合わせた刺激量の調整
  • 腹部の反応だけでなく、呼吸・動作・本人の感じ方を確認する
  • 一度に多くの介入を重ねず、何に反応したかを比較する
  • 変化がない場合・悪化する場合の中止と再検討、変化を運動や日常動作につなぐ

安全な判断と連携

  • 施術を進めず医療評価を優先する状況（急な強い腹痛、発熱、繰り返す嘔吐など）
  • 術後、妊娠、既往疾患、服薬などの確認
  • 腹部への強い圧迫を避ける判断
  • 説明と同意、記録、施術者の業務範囲と医療機関への相談
6．ケース実践・生活への応用代表的なケースを題材に、評価から提案・記録までの流れを通して練習します。

ケースの例

  • 食後の張りが気になる人
  • 腹部の緊張と呼吸の浅さを感じる人
  • ストレスや睡眠不足とともに不調を訴える人
  • 腹部の不快感と動作のしにくさを訴える人

練習する流れ

  • 問診 → 安全確認 → 腹診・舌診・脈診 → 呼吸・動作評価 → 仮説 → 介入選択 → 再評価 → 生活・運動の提案 → 記録
  • 「施術する判断」だけでなく「施術せず相談を勧める判断」も扱う

DIFFERENCE

ほかの零式講座との違い

内臓を強く押し動かすことを目的とせず、東洋医学の見立て（腹診・舌診・脈診）と、臓器の解剖・生理・神経系の知識を組み合わせて評価し、介入を選ぶ講座です。頭部・頸部からのアプローチは零式-ヘッドコンディショニング極、全身の施術設計は零式-ZERO RECOVERYで扱います。

FAQ

よくある質問

内臓の病気を治す講座ですか？

いいえ。病気の治療ではなく、身体の反応や機能を評価し、施術者の業務範囲で介入を選ぶための講座です。医療評価を優先すべき状況の判断も扱います。

1日ですべての臓器の手技を習得できますか？

いいえ。1日で全臓器の詳細と全実技の習得を約束するものではありません。講座での扱いの深さと時間配分は受付開始時にご案内します。

東洋医学の知識がなくても受講できますか？

カリキュラム案では、腹診・舌診・脈診や実証・虚証を基本から扱う予定です。事前学習の有無は受付開始時にご案内します。
